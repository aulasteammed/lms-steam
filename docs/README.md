# Documentación del Proyecto LMS STEAM

Esta carpeta centraliza la documentación funcional y técnica del sistema.

## Estructura

- `usuario/manual-usuario.md`: guía para usuarios finales de la plataforma.
- `tecnica-arquitectura/arquitectura-sistema.md`: arquitectura lógica y componentes.
- `tecnica-arquitectura/instalacion-despliegue.md`: instalación, configuración y despliegue.
- `tecnica-arquitectura/modelo-datos.md`: modelo de datos y relaciones de base de datos.
- `tecnica-arquitectura/mantenimiento.md`: recomendaciones, cuidados y necesidades de mantenimiento.
